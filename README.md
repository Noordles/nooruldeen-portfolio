# Nooruldeen.com

I’m Noor, and this is my personal website a small place to share a little about who I am and the work, ideas, music, and photography I enjoy.

Visit [nooruldeen.com](https://nooruldeen.com) to explore the site.

I’m sharing the code here in case it inspires you to make something of your own.

## Private owner content management

The owner CMS adds editable text on every page, shared website fields, photography and piano managers, a reusable media library, private drafts and explicit publication without changing the public page templates or styling.

- [Owner guide](admin/OWNER-GUIDE.md)
- [Account setup, deployment and security boundaries](admin/DEPLOYMENT.md)

The service must be provisioned with the owner's managed authentication, database, private storage and server publishing credential before /admin becomes usable. The checked-in placeholder configuration cannot authenticate or publish.
